# Ako & Salo — Wedding Invitation

A mobile-first, cinematic digital wedding invitation built with semantic HTML, CSS, and vanilla JavaScript.

## Personalise

Edit `dist/js/config.js` to change the names, date, venue, schedule, dress code, image path, and optional music path.

## Run locally

Serve the `dist` folder with any static server. For example:

```bash
npx serve dist
```
